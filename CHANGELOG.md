# Changelog

Все значимые изменения проекта фиксируются в этом файле.

Формат версий: MAJOR.MINOR.PATCH

- MAJOR — несовместимые изменения / крупная переработка
- MINOR — новый функционал и заметные улучшения
- PATCH — исправления ошибок и мелкие изменения

---

# Памятка

- Added — новый функционал 
- Changed — изменили существующее поведение 
- Fixed — багфиксы 
- Removed — удалённый функционал 
- Notes — любые комментарии/ограничения/важные замечания

---

# [1.1.1] - в процессе

## Added
- добавлена функция combine_mzs_to_polygon для буфферизации полигонов МЗС

## Changed
- обновлена библиотека reservoir_maps: скорректирована логика адптации ОФП при конфликте исходных  данных (начальная нефтенасыщенность, обводненность и ОФП)

## Fixed
- ошибка в буфферизации МЗС (get_parameters_voronoi_cells и save_picture_voronoi), стволы располагались очень близко, получалась ошибка пересечения. Исправлена логика и в дополнении сортировка порядка точек в МЗС.

## Removed
- удалена функция для объединения координат МЗС в одну линию combine_to_linestring

# [1.1.0] - 2026-05-15

## Added
- добавлена функция save_excel_inj_wells для выгрузки параметров по нагнетательным скважинам в т.ч. полезной закачки
- добавлена отдельная функция save_excel_permeability_fact_wells для выгрузки параметров по факт фонду, выгрузка дополнена эффективными радиусами 
- созданы файлы для контроля версий и задач: CHANGELOG.md и BACKLOG.md 

## Changed
- изменена main функция в drilling_zones для генерации картинок сочетаний гиперпараметров кластеризации: теперь автоматически картинки разбиваются на листы и есть возможность задавать диапазон процента лучших точек
- обновлена функция save_picture_voronoi: картинка дополнена эффективными зонами скважин, также появился режим подписи скважин по углам объекта для более удобной привязки картинки в NGT Smart
- обновлен мануал с учетом всех изменений

## Fixed
- ошибка в переименовании local_parameters на русский: Степени Corey по воде/нефти были перепутаны местами
- разблокирована выгрузка контуров зон бурения (save_contours): пофиксен баг с очень маленькими зонами, теперь они не прерывают расчет, а идут в лог
